# THE SEA — Elite Gallery Finance OS

Welcome to **THE SEA Finance**, an elite gallery management system designed for professional curators and gallery owners. This application has evolved from a simple bot into a comprehensive, high-end financial suite that surpasses standard industry tools in depth, intelligence, and operational control.

## 🪓 Power Finance Pillar

**THE SEA** is built on four "Power Pillars" that provide maximum financial clarity:

1.  **Proactive Intelligence (SEA AI)**: An elite AI analyst that identifies "cost centers," analyzes burn rates, and suggests optimizations in real-time.
2.  **Artist ROI Matrix**: Deep profitability tracking per artist, deducting direct production and logistics costs from gallery shares to show true net contribution.
3.  **Receivables & Cash Flow**: Advanced tracking of sold artwork balances, expected payment dates, and cash collected vs. outstanding receivables.
4.  **Forecasting Engine**: Real-time projections of final exhibition outcomes based on current sales pace and daily burn rates.

## 💎 Elite "SEA OS" Interface

The system features a stunning **Glassmorphism Design System** (Sapphire Blue theme) mirroring top-tier SaaS platforms:
- **Bento Home Screen**: A unified portal for all gallery operations.
- **Multi-Tab Shell**: Seamless switching between Dashboard, Inventory, ROI Matrix, and the SEA AI Analyst.
- **Formula-Driven Excel Exports**: Professional, multi-sheet workbooks (`Executive Summary`, `P&L`, `Budget vs Actual`, `Actual Ledger`, `Paintings List`, `Artist ROI`, `Receivables Aging`, and `Audit Log`) that perfectly match top-tier gallery standards with live formulas.

## 🛠 Setup & Deployment

### Local Setup
1.  Install dependencies: `pip install -r requirements.txt`
2.  Configure `.env` with `OPENAI_API_KEY` (optional, for SEA AI) and `TELEGRAM_BOT_TOKEN` (optional).
3.  Run the suite: `python main.py`

### Deployment on Render
1.  Upload this repository to GitHub.
2.  Create a **Web Service** on Render.
3.  Set `TELEGRAM_BOT_TOKEN` (optional) and `OPENAI_API_KEY` (optional) in environment variables.
4.  Render will auto-detect the `render.yaml` and `Dockerfile`.
